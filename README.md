# 教室PR作成ツール（PRチラシメーカー）

教室の無料体験チラシを作るツールです。HTMLファイル1つで動きます（外部ライブラリなし。地図だけはネットにつながっているときに使えます）。

- `教室PR作成ツール.html` … パソコンに保存して、ダブルクリックで開いても使えます
- `教室PR作成ツール.zip` … Netlify Drop 用（中身は `index.html`）。https://app.netlify.com/drop にドラッグ＆ドロップすると公開できます

## 会費の金額を変えるには

`教室PR作成ツール.html` をメモ帳などで開いて、上のほうにある `const FEES = {` の数字を書き換えて保存します。

```js
const FEES = {
  tokyo:{ name:'東京・神奈川', kid:'〇,〇〇〇', jh:'〇,〇〇〇', hs:'〇,〇〇〇' },
  other:{ name:'その他の地域', kid:'7,480', jh:'8,580', hs:'9,680' },
};
```

`kid` が幼児・小学生、`jh` が中学生、`hs` が高校生（1教科あたり・税込）です。「円」は自動で付きます。
書き換えたあとは、zip も作り直してください（`index.html` という名前にして zip にする）。
