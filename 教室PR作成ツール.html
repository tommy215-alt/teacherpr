用紙サイズを選んでください

選んだサイズでPDFに書き出されます。デザインはどのサイズでも同じ比率で拡大・縮小されます（あとから「⑥ 詳細な編集とレイアウト」の「ページの背景」でも変更できます）。

はじめにお読みください（注意点）
  • 【いちばんかんたんな作り方】用紙サイズ → テンプレートを選んだら、「③ かんたん入力」で無料体験の名前・教室名・住所・曜日などを入れるだけ。「このままPDFにする」で完成です。背景・色・細かい配置は「もっとこだわる」からあとで変えられます。
  • 【スマホ・タブレット】テンプレート選び・かんたん入力・PDFの保存までできます。スマホでPDFを保存するときは、出てくる画面の「共有・保存する」から「"ファイル"に保存」などを選んでください。細かい編集（配置の調整など）はパソコンがおすすめです。
  • 【保存のしかた】右上の「保存」ボタン（または CtrlS）を押します。保存したチラシは、上のメニュー「保存したチラシ」→「開く」でいつでも呼び出せます。
  • 【気をつけること】保存先は「今使っているパソコンの、今使っているブラウザ（Chrome など）」の中です。別のパソコンや、同じパソコンでも別のブラウザ（Edge など）で開くと、保存したチラシは表示されません。また、ブラウザの設定で「閲覧履歴データの削除」→「Cookie と他のサイトデータ」を消すと、保存したチラシも消えてしまいます。
  • 【バックアップのしかた】①上のメニュー「保存したチラシ」を開く → ②「全部をファイルに書き出す（バックアップ）」を押す → ③「チラシ_バックアップ_日付.json」というファイルがダウンロードフォルダに保存されます。USBメモリやクラウド（Google ドライブなど）にコピーしておくと安心です。1枚だけ残すときは、そのチラシの「ファイルに書き出す」を押します。
  • 【別のパソコンで続きを編集するには】①そのパソコンでも、このツール（教室PR作成ツール.html、またはWebに公開したURL）を開く → ②「保存したチラシ」→「ファイルから読み込む」を押す → ③書き出した .json ファイルを選ぶ → ④一覧に出てきたチラシの「開く」を押す。
  • フォントはパソコンに入っているものを使います。入っていない場合は似たフォントで表示されるため、別のパソコンでは見た目が変わることがあります（PDFにすれば見た目は固定されます）。
  • 【PDFの書き出し】右上の「PDFで書き出し」を押すと、選んだ用紙サイズのPDFがダウンロードフォルダに保存されます（印刷の設定は不要です）。画像を入れていない枠は空欄のまま書き出されます。
  • テンプレートの文章・数値は見本です。実績の数値やキャンペーン内容は最新の公式情報や本部の案内でご確認のうえ、教室の内容に合わせて書き換えてください。「生徒の声」は実際の声に差し替えてください。
  • チラシの作成・配布に関する本部のルール（ロゴの扱いなど）がある場合は、そちらに従ってください。顔写真を載せるときは、ご本人（保護者）の了承を得てください。

テンプレートを選んでください

写真をたくさん使うテンプレートから順に並んでいます。入力した文字や画像はそのままに、あとからテンプレートを変えることもできます。　

入力するとすぐに反映されますチラシをタップすると大きく表示します
選んだ模様・枠がすぐに反映されます（あとから何度でも変更できます）
選んだ配色がすぐに反映されます（あとから何度でも変更できます）
プレビューの文字・画像をクリックすると、その入力欄に移動します

別のパソコンやブラウザでは見えません。大事なチラシは「全部をファイルに書き出す」で .json ファイルにして、USBメモリやクラウドに残しておくと安心です。

    PDFができました

    1. iPhone・iPad：「共有・保存する」→ 一覧から「"ファイル"に保存」を選ぶ（LINE やメールで送ることもできます）
    2. Android：「PDFを開く／ダウンロード」→ 画面の下に出る「開く」、または通知から確認できます（ダウンロードフォルダに保存されます）

    印刷画面からPDFを保存する

    このブラウザではPDFを直接作れなかったため、印刷画面から保存します。

    1. 送信先（プリンター）で「PDFに保存」を選ぶ
    2. 用紙サイズ A4／余白 なし（倍率は「100%」または「デフォルト」）
    3. iPhone・iPad：印刷画面（オプション）が出たら、右上の共有ボタン（□に↑）→「"ファイル"に保存」を選ぶ
    4. Android：印刷画面の上の「プリンタを選択」で「PDF形式で保存」を選び、PDFのボタンを押す
    5. 詳細設定の「背景のグラフィック」にチェック
    6. 「保存」を押す
